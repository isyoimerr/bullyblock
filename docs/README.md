## Visión general

BullyBlock es una aplicación web mobile-first para estudiantes, docentes y psicoorientación, pensada para reportar situaciones de acoso, pedir apoyo inmediato y gestionar casos con claridad y seguridad.

## Objetivos

- Dar una experiencia móvil simple y segura.
- Permitir reportes rápidos con flujo guiado.
- Separar roles con permisos y visibilidad limitada.
- Proveer un panel para psicoorientación con seguimiento y métricas.
- Preparar la base para despliegue profesional en Vercel con Supabase.
